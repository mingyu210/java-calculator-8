# java-calculator-precourse

# 📘 프로젝트 개요

이 프로그램은 **입력된 문자열에서 숫자를 추출하여 더하는 계산기**입니다.  
기본 구분자(쉼표 `,` 와 콜론 `:`) 또는 커스텀 구분자를 이용해 숫자를 분리하고,  
그 숫자들의 합을 계산하여 결과를 출력합니다.

---

# ⚙️ 구현할 기능 목록

### 1. 입력 처리
- 사용자로부터 문자열 입력 받기
- 문자열이 비어있을 경우 `0`을 반환

### 2. 기본 구분자 처리
- `,`(쉼표), `:`(콜론)을 기준으로 숫자를 분리

### 3. 커스텀 구분자 처리
- `"//"`와 `"\n"` 사이에 있는 문자를 커스텀 구분자로 인식
- 예: `"//;\n1;2;3"` → 구분자 `;`

### 4. 문자열 파싱 및 합 계산
- 분리된 숫자들을 정수형으로 변환하여 모두 더함

### 5. 예외 처리
- 숫자가 아닌 값이 포함된 경우 → `IllegalArgumentException` 발생 후 종료
- 음수 입력 시도 시 → `IllegalArgumentException` 발생
- 빈 문자열일 경우 → `0` 반환

### 6. 출력
- 계산 결과를 `"결과 : X"` 형태로 출력

---

# ⚠️ 예외 처리 계획

| 상황 | 처리 방법 |
|------|-----------|
| 잘못된 구분자 사용 | `IllegalArgumentException` 발생 |
| 숫자 이외의 문자가 포함됨 | `IllegalArgumentException` 발생 |
| 음수 입력됨 | `IllegalArgumentException` 발생 |
| 빈 입력 문자열 | `0` 반환 |
